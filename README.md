
# Housing Price Regression

## Description
This project predicts housing prices using machine learning regression models.

## Models Used
- Linear Regression
- Decision Tree Regressor
- Random Forest Regressor

## Dataset
Synthetic housing dataset with features like bedrooms, bathrooms, sqft, location, etc.

## How to Run
1. Install dependencies:
   pip install scikit-learn pandas numpy
2. Run:
   python housing_price_model.py

## Evaluation Metrics
- MAE
- MSE
- R2 Score

## Result
Random Forest generally performs best due to lower error and higher R2 score.
